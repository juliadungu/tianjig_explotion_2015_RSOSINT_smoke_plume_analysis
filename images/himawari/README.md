# Himawari-8 source material

This directory contains the CIMSS three-satellite shortwave-infrared animation used for the immediate-event analysis:

`HIMAWARI3PAN_NOMAP_12AUGUST2015_1500_1900anim.gif`

Primary source:
https://cimss.ssec.wisc.edu/satellite-blog/wp-content/uploads/sites/5/2015/08/HIMAWARI3PAN_NOMAP_12AUGUST2015_1500_1900anim.gif

CIMSS article:
https://cimss.ssec.wisc.edu/satellite-blog/archives/19209

The animation contains three panels with independent timestamps:

- Himawari-8 — 3.9 µm (top)
- MTSAT-2 — 3.75 µm (middle)
- COMS-1 — 3.75 µm (bottom)

For the primary H1–H3 chronology, only the Himawari-8 top panel is used. The full composites are retained for provenance.

Selected Himawari times:

- H1 — 15:30 UTC
- H2 — 15:40 UTC
- H3 — 17:50 UTC

Do not treat the three panels as simultaneous: their embedded timestamps differ.
